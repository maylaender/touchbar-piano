# Song sources

All built-in songs are complete pieces (or movements) generated by [`tools/make_songs.py`](../tools/make_songs.py)
from the sources below. Each file has two tracks: **melody** (right hand, used for sheet/learn mode) and
**accompaniment** (left hand, inner voices, ornaments). Only the arrangement into these two tracks was done here –
the notes are unchanged.
