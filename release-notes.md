Touch Bar Piano – 2 octaves (C4–C6), multitouch, universal (Intel + Apple Silicon).

**Install:** download `Piano.app.zip`, unzip (double-click), then in Terminal:

```sh
xattr -dr com.apple.quarantine Piano.app
open Piano.app
```

Tip: System Settings → Keyboard → Touch Bar → "App Controls", Control Strip off – full width for the piano.
