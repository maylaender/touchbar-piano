**Touch Bar Piano v3** – the biggest update so far. Universal (Intel + Apple Silicon), macOS 11+.

- 🎹 Full-width Touch Bar, Esc hidden, works system-wide
- ✨ New macOS-style window – everything clickable, all shortcuts still work
- 🎻 32 instruments + 🥁 drum mode with 3 kits
- ⏺ Recorder with playback and lit keys
- 🎼 Classics by Mozart, Beethoven, Bach & Brahms
- 📖 Sheet mode with falling notes and a learn mode that waits for you
- 🎛 MIDI import & export
- 🌍 English / German (follows macOS)

**Install:** download `Piano.app.zip`, unzip, then in Terminal:

```sh
xattr -dr com.apple.quarantine Piano.app
open Piano.app
```
